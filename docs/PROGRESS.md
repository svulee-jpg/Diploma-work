# Журнал прогресса

## 22.11.2026 (вечер): реальное распознавание лиц
**Сделано**
- Движок InsightFace (`buffalo_l`, ArcFace) подключён и проверен: модель хранится в `backend/data/insightface/` (не в git, ~280 МБ, скачивается при первом запуске).
- Проверка на тестовом снимке из пакета: найдено 6 лиц; один человек (оригинал и зеркальное отражение) даёт косинусное сходство ≥ 0,93, разные люди ≤ 0,21. Это лёгкие условия: для реальных (свет, ракурс, маска) порог нужно калибровать.
- Порог сопоставления теперь настраивается (`SMARTPOS_MATCH_THRESHOLD`, по умолчанию 0,45).
- В интерфейс бариста добавлен захват с веб-камеры (в режиме `insightface` вместо симуляции); кадр не сохраняется, на сервере остаётся только вектор.
- Интеграционный тест реального движка (`tests/test_insightface.py`): регистрация лица, повторное узнавание, отказ на кадре без лица. Всего 7 тестов проходят.

**Дальше**

- Защита от подмены (фото на экране телефона): liveness-проверка, пока не реализована.
