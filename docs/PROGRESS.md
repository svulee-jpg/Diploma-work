# Журнал прогресса

## 22.11.2026: старт проекта
**Решено**
- Ядро диплома: Smart POS (распознавание гостя + рекомендации бариста); тема из заявления раскрывается как СППР уровня кассы (см. [CONCEPT.md](CONCEPT.md)).
- Данных кофеен пока нет, поэтому на старте синтетический датасет с явными правилами; план получения реальных данных нужно обсудить с руководителем.

**Сделано**
- Каркас репозитория, README, документация.
- Бэкенд на FastAPI + SQLite: идентификация, карточка гостя, рекомендации, холодный старт, чекаут с бонусами, отзыв согласия, метрика конверсии подсказок.
- Модуль лиц: FAISS-индекс; движки `simulated` (демо) и `insightface` (реальный, ещё не проверен на камере).
- Рекомендательная модель (логистическая регрессия, гибрид) + офлайн-оценка против бейзлайнов.
- Интерфейс бариста (проверен вручную в браузере на сценарии «Сауле»).
- 5 автотестов проходят.

**Следующие шаги**

2. Согласовать с руководителем источники реальных данных (обезличенные чеки Espresso Day / Luna Coffee).
3. Распределить главы между Сауле, Алинуром и Аделью.
4. Литературный обзор (глава 1) и юридический раздел (закон РК о персональных данных).
5. Экономическая модель эффекта и дизайн A/B-пилота.
