# Структура дипломной работы (черновик)

**Введение:** актуальность (рост конкуренции в кофейнях, лояльность, давление на маржу), проблема (трение на кассе, неперсональные допродажи, списания), цель, задачи, объект/предмет, гипотезы, новизна, практическая значимость.

**Глава 1. Теоретические основы**
1.1 СППР и ИИ в операционном управлении сферы HoReCa
1.2 Программы лояльности и персонализация на кассе (upsell / cross-sell)
1.3 Распознавание лиц: детекция, эмбеддинги (ArcFace), векторный поиск; метрики FAR / FRR / TAR
1.4 Рекомендательные системы: персональные, коллаборативные, гибридные, холодный старт
1.5 Правовое регулирование биометрии в РК; этика и приватность
1.6 Анализ аналогов (Poster / iiko / r_keeper лояльность, Amazon Go, примеры face-pay)

**Глава 2. Анализ и проектирование**
2.1 Анализ бизнес-процесса «касса» в Espresso Day / Luna Coffee (интервью, замер времени)
2.2 Требования (функциональные, нефункциональные, приватность)
2.3 Архитектура: CV-модуль, Recommendation Engine, Backend, интерфейс; диаграммы (C4, ER, sequence)
2.4 Данные: схема БД, синтетические данные, план сбора реальных

**Глава 3. Реализация и эксперименты**
3.1 Реализация модулей (код в репозитории)
3.2 Оценка распознавания: точность, порог, FAR/FRR на тестовой выборке лиц
3.3 Оценка рекомендаций: AUC, hit@1, сравнение с бейзлайнами (`python -m smartpos.evaluate`)
3.4 Пилот / A/B-сценарий: конверсия подсказок, средний чек, время обслуживания
3.5 Экономический эффект: допродажи, снижение списаний, окупаемость

**Заключение**, **Список литературы**, **Приложения** (код, скриншоты интерфейса, схемы).
