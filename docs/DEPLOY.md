# Публикация демо по ссылке (Render)

Демо-версия: симуляция распознавания лиц (реальная камера и InsightFace на хостинге не работают), вымышленные данные,
дашборд заполняется смоделированной активностью за 2 недели. Защищена паролем.

## Шаги (один раз, ~10 минут)
1. Зайдите на https://render.com → **Sign in with GitHub** (аккаунт `svulee-jpg`) → разрешите доступ к репозиторию `Diploma-work` (он закрытый, Render берёт код через GitHub-приложение).
2. **New +** → **Blueprint** → выберите `Diploma-work` → Render найдёт `render.yaml`.
3. Когда попросит значение `SMARTPOS_DEMO_PASSWORD`, придумайте пароль (его увидит только Render и вы; в git он не попадает) → **Apply**.
4. Через 5–10 минут появится ссылка вида `https://smart-pos-demo.onrender.com`. Браузер спросит логин (любой, например `demo`) и пароль.

## Адреса экранов
`/` киоск · `/queue` очередь · `/board` табло · `/dashboard` дашборд · `/barista` экран персонала

## Что важно знать
- **Бесплатный тариф засыпает** после ~15 минут без заходов; первое открытие после сна занимает около минуты. Перед показом комиссии откройте ссылку заранее.
- **База сбрасывается** при каждом перезапуске (диск временный): это ожидаемо для демо, данные создаются заново.
- **Реальная камера:** только локально (`SMARTPOS_FACE_ENGINE=insightface`, см. README). Публиковать реальную биометрию в облаке без юридической проработки нельзя.
- **Пароль и патент:** публичная ссылка без пароля это раскрытие идеи (см. [IP_AND_NOVELTY.md](IP_AND_NOVELTY.md)). Делитесь ссылкой и паролем только с командой, руководителем и нужными людьми.
- Любые правки в `main` на GitHub Render подхватывает и пересобирает автоматически.
